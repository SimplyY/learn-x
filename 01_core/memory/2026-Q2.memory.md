# Learn-X Memory｜2026-Q2

## 候选观察池

### 道候选

- [Monthly｜2026-04] 道：**工程师造笼，诗人会死；工程师造园，诗人才住得下。工程师的最终修养，是学会不建。做减法，无为**。
- [Monthly｜2026-05] 道：AI 时代最重要的是守住主体性、真实关系、身体和判断力。
- [Monthly｜2026-05] 道：心底之问——今天是否更像苏轼、孟岩、孔子？

### 法候选

- [Monthly｜2026-04] 法：笼式教育是控制孩子。园式教育是提供环境，让人自驱生长。
- [2026-W22] 法候选：AI 赋能先找真实闭环，不先设计完整系统。
- [2026-W24] 法候选：判断一件事是否长期适合自己，先问“它在滋养我吗？”
- [2026-W25] 法候选：点燃孩子兴趣，先接住并放大已有作品，再引入工具、课程和任务。
- [2026-W26] 法候选：AI 教育先诊断真实人，再选择工具和任务。未来的教育应该是水、火、魂三位一体的。
- [2026-W27] 法候选：教育赋能先找有火种的人，再给 AI 杠杆。
- [2026-W27] 法候选：AI Agent 落地先降入口摩擦，再沉淀 Skill，最后自动化。

### 术候选

- [2026-W24] 术候选：每次录播客之前，提炼 3-5 个核心问题

### 芒格之魂手动洞察候选

- [Monthly｜2026-05｜真实闭环] 洞察：Learn-X 的价值，不取决于它能沉淀多少认知，而取决于它能帮你少想多少废问题，多做多少真闭环。它是否让我仍然拥有自己的身体、生活和心？
- [2026-W23｜AI 与真实世界] 洞察：AI 是剑，但真实世界才是磨刀石，这把剑有没有砍到真实问题？否则 ai 就是茧
- [2026-W23｜身体与判断] 洞察：身体状况决定能量状况，能量状况决定判断质量。
- [2026-W24｜生命秩序] 洞察：真正需要的不是单纯高效或赚钱，而是一种同时容纳身体、投资安全边际、主体性、教育意义、诗性、朋友和小而美事业的生命秩序。
- [2026-W24｜时间尺度] 洞察：不要用一天的焦虑否定十年的方向，也不要用十年的愿景逃避今天的行动。
- [2026-W25｜反馈回路] 洞察：底层本质：你真正需要的不是更多系统，而是更短反馈回路。
- [2026-W25｜系统选择] 洞察：不要追求每个方向都做对。你只需要避免把生命能量投入低反馈、高维护、伪进展的系统里。
- [2026-W26｜智慧之门] 洞察：智慧之门必须通向真实生活；如果只通向更多整理，它就不是门，是柜子。
- [2026-W26｜教育支点] 洞察：教育方向的支点不是“AI 教育”，而是用 AI 降低创造门槛、用关系点燃成长，为家庭创造更容易出现作品、榜样、反馈和自驱的成长场。
- [2026-W26｜创作现场] 洞察：创作不是靠在屋里优化系统，而是靠真实世界激发胸中块垒。
- [2026-W27｜主体性] 洞察：AI 更适合成为主体性增强器，帮助人看清问题、降低行动摩擦、形成作品并获得反馈；但要警惕把搭建系统的兴奋误认为现实进展。
- [2026-W27｜生命校验] 洞察：不要问系统是否更强，问生命是否更自由；不要问工具是否更快，问判断是否更清醒；不要问内容是否更多，问它有没有回到真实世界。
