# 人生核心议题知识库

「人生核心议题」是 Learn-X 的统一研究档案，唯一原文在私有飞书 Wiki 中保存。

- `总览`：每季度一篇，盘点全部议题、优先级、研究状态和下一季候选动作；目录页只维护新到旧索引。
- `细项研究`：每月一篇，记录当月选题、证据、判断和待提交回填；目录页只维护新到旧索引。
- Base 是结构化状态、认知事件和审计账本的真值源；Wiki 是人类阅读与研究原文，不生成分叉副本。
- 只有文档中的明确「回填清单」结论可以提交；自由研究区、草稿和普通笔记不会自动写入 Base。
- 写入前必须校验文档 revision/hash、字段白名单和证据锚点；失败关闭，不覆盖用户内容。
- 索引每次根据真实 Wiki 子节点全量重建，并按 `YYYY-QN` 或 `YYYY-MM` 倒序；不依赖侧边栏兄弟节点顺序。
- 季度和月度 Skill 都支持同名模板恢复、幂等重试、审计和撤回；撤回新建议题时只关闭研究，不物理删除。

当前共享配置见 `00_config/core-question-library.json`（空间 `7685945374065839292`）；季度提醒 Workflow 为 `wkf6MmPr25BW38Ir`。目录页由程序管理，研究正文由人工维护和确认。

## Learn-X 群快捷入口

`chat_tab` 配置只属于 `learn-x` 群，固定标签名为「人生核心议题」，链接始终指向当前季度总览 Wiki 节点。季度 `create`（新建或复用）会尝试同步；也可用 `sync-tab --quarter YYYY-QN` 单独重试。飞书“消息”标签由平台固定第一，“人生核心议题”必须位于第一个自定义标签；同步失败只记录为“需重试”，不回滚知识库，也不写入 README、GROUP_INFO 或 Base 的链接字段（季度账本的 `解析摘要.chatTabSync` 会记录状态）。
