# Learn-X 长期认知议题

## 为什么需要

Learn-X 已经能把输入变成理解、Output、Memory 和上下文，但长期系统还缺少一条稳定链路：

```text
重要议题 → 增量证据 → 阶段判断 → 决策 → 行动/实验 → 现实结果 → 认知校准
```

长期认知系统不追求保存更多文档，而追踪有限注意力应该持续投入的真正议题，以及自己为什么改变判断。

## 核心原则

- Base 中的议题是业务真值源；Markdown 只维护系统目标、边界和工程规则。
- 温故与复盘分开：智慧之门让重要内容再次出现，议题复盘比较变化并触发下一步思考。
- 只记录对判断产生实际影响的事件，不给所有材料批量贴标签。
- 当前判断可以快速查看，但认知变化必须以追加事件保留历史。
- 最强反证、最大未知和改变判断的条件与支持证据同样重要。
- 可逆、低成本且反馈快的事情优先进入现实实验；继续研究必须说明可能改变什么选择。
- AI 负责聚合、比较、提问和组装上下文；人负责价值判断、选择和确认。
- 新经历可以产生全新问题，不能把所有输入强行归入已有议题。

## 对象与边界

「议题」是唯一原子对象，可以是问题，也可以是目标。问题与目标相关，但不要求一一对应；目标通常更接近中期和短期，长期问题可以不设目标。现有 `类型` 仍表示工作模式：长期问题、年度重点或重大决策；它不是第二个业务对象。类型变化保留同一编号，并在「认知事件」中记录原因。

「认知事件」以内容摘要、详细内容和关联议题作为最小人工记录；事件类型、证据方向、判断前后、来源标识/链接和认知增量用于需要时的结构化补充。它可以记录证据、判断更新、决策、行动、现实结果、校准和问题重构。Voice-X、Research-X、Read-X 与 Doing-X 继续拥有原始材料和行动记录，事件不复制外部原文。

Learn-X 拥有议题索引、月度注意力配置与 ChatGPT 上下文组装；Research-X 的 `wisdom-review` 只负责共享每日温故；现实行动和结果由人的现实经历或相应系统产生。议题 Skill 不提供日常 CRUD，也不替用户写判断或作决定。

已建立的「相关议题」关系会进入 Chat Pack；事件的增量判断按创建/更新时间追踪，事件实际发生时间只用于理解时间线。

## 月度议题研究工作台

长期认知系统需要的不只是按日期复盘，更是把有限注意力重新配置到真正重要的议题。月度工作台从活跃议题中用确定性规则推荐候选，人自行选择后在一份飞书工作台持续研究；提交只解析明确变化，Base 更新当前状态并追加真实认知事件。

工作台不替人判断价值，不把系统动作算作认知进展，也不要求每次提交产生事件。议题周期、优先级与研究状态独立：前者区分短期/中期/长期的主要注意力窗口，优先级是整体重要性，研究状态是当前是否继续投入注意力。完整产品边界见 [月度议题研究工作台](MONTHLY_CORE_QUESTION_WORKBENCH.md)，工程契约见 [TECH](TECH.md)。

## 两种回顾

- **每日温故**：复用智慧之门现有共享配额和间隔，标题是议题，摘要是当前判断。
- **月度深度研究**：先审计议题组合并推荐候选，再由人选择进入一份工作台。研究不受固定天数或议题数量约束；当前周复盘暂时停用，未来独立重做。

月度工作台只提供少量结构化锚点和自由研究区。提交后，明确的状态变化与真实认知事件才进入 Base；没有进展可以不产生事件。

## 深度研究

月度调度之外，任何议题、临时问题或现实经历都可以随时触发一键深度研究：系统自动创建「人生核心议题/深度研究」目录下的 Wiki 文档，注入研究模板、当前判断、最大未知和近期认知事件。深度研究是按需发生的一等研究资产，不属于月份或季度；月度推送只是它的可能入口之一。研究造成真正认知变化时，由人在「认知事件」记录并以来源链接指向研究文档；没有变化就不产生事件。完整产品边界见 [深度研究系统](DEEP_RESEARCH.md)。

## 现实闭环

复盘不是思考机器。重大决策必须有时间窗口、可逆性和退出机制；行动和结果由 Doing-X 或现实经历产生，再以事件回到议题。长期价值来自判断被现实校准，而不是复盘次数或摘要数量。

## P0 后的观察点

- 至少三个真实月度周期后，再观察推荐是否常被推翻、哪些文本最易误判为事件、撤回比例、未解决审计状态，以及 P0 议题是否持续缺少注意力。
- 行动门与结果校准仍要靠真实决策验证；在积累足够结果前，不制造准确率或自动评分。
- 这些观察用于发现系统偏差，不给用户打分，也不自动调优优先级。

## 当前版本非目标

第一版不建设本地议题数据库、图数据库、RAG、自动分类、跨 Base 全量同步、自动决策、议题 Markdown 镜像、复杂 UI、表单或仪表盘。连续运行产生真实数据后，再决定是否需要统计分析或候选发现。

## 人生核心议题知识库

季度总览、月度细项研究和按需深度研究统一进入私有飞书 Wiki「人生核心议题」；总览、细项研究、深度研究三个目录页只保存按时间倒序的机器索引。Base 继续保存结构化状态、认知事件与审计账本，人工确认后的明确回填才允许写入。
