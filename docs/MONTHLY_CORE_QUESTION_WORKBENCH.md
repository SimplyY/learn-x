# 月度议题研究工作台

## 它解决的问题

Learn-X 已经能把输入转成理解、Output、Memory 和 Chat Pack，也能在 Base 保存议题和认知事件。但这些能力没有回答更上游的问题：当议题越来越多，有限的深度注意力该重新进入哪里。

按日期复盘只解决“何时再出现”，不解决“什么值得投入”。如果把普通到期事项、日常输入与重要议题放进同一提醒队列，系统会积累总结和记录，却未必推动阶段判断、行动或现实反馈。更糟的是，人会开始为维护表格服务。

月度工作台因此不是提醒器、待办、月报或自动价值判断系统。它是一个低干预的闭环：系统给出可解释候选，人选择，一份飞书文档承载数日乃至更久的自由研究，AI 只把明确发生的变化结构化沉淀回 Base。

「议题」是系统的原子对象，可以是问题，也可以是目标。问题与目标相关，但不要求一一对应；目标通常更接近中期和短期，长期问题可以不设目标。

## 产品宪法

- 人的持续深度注意力是稀缺资源；推荐每层至多两个、默认选择三个只是起点，不是配额。
- 系统可以推荐，不能替人决定什么最重要。用户可以少选、多选、全选、删除候选、加入既有候选外议题，以及随时修改优先级。
- `优先级`回答议题整体有多重要；`研究状态`回答它此刻是否值得继续投入注意力。二者独立。P0 可以暂缓，临近截止的 P2 重大决策也可以进入候选。
- `议题周期`回答议题主要通过哪个注意力窗口取得进展：短期面向未来 4–12 周的现实行动或反馈，中期面向未来 6–24 个月的验证与积累，长期面向更长的人生方向或世界理解。它不等于优先级，也不等于研究状态；空值保留为未分类，等待人维护。
- 默认是继续研究。只有人明确写出暂缓或关闭时才退出自动推荐；关闭研究不删除议题，也不改变议题生命周期。
- 飞书文档是人的研究现场，允许混乱、停顿、反复和自由组织。Base 保存机器可读的当前状态、追加历史与流程审计。文档不是另一张多维表格。
- 提交只表示“解析当前文档版本”。它不表示研究完成、全部议题有结论、议题关闭，或一定产生事件。
- 只有新证据、判断更新、问题重构、决策、行动/实验、现实结果或校准才是认知事件。推荐、选择、建文档、消息送达、提交、优先级或研究状态的改动本身都不是事件。
- AI 只提取文档中明确表达的变化，不能从模糊笔记补全个人事实或价值判断。无明确进展时允许 0 条事件。
- 回写默认直接进行，降低研究收尾摩擦；但每次写入都必须可查看、以文档新版本完整替换，或撤回。追加事件永不删除，只标记撤回。

## 角色边界

| 角色 | 负责 | 不负责 |
|---|---|---|
| 人 | 议题选择、优先级、研究、判断和纠错 | 持续维护机器字段 |
| 飞书工作台 | 自由研究与少量稳定锚点 | 最终机器历史 |
| Base | 当前状态、认知事件、版本审计 | 替代研究过程 |
| AI | 从明确文本提出结构化变更并校验回写 | 自动判断价值、制造进展 |

## 与其他系统的关系

月度工作台负责重要议题的注意力配置与深度研究。未来周机制负责近期变化和临近决策；Voice-X、Research-X、Read-X 提供各自原始证据；现实行动和结果由现实经历或相应系统产生。它们可以成为议题证据，但不自动决定优先级。

## P0 的边界

P0 不监听文档、不建 RAG/向量库/图数据库、不抓取其他系统、不做前端或复杂消息卡片，也不兼容旧复盘 Skill。只有出现至少三个真实周期中重复、明确的摩擦，才评估更复杂的排序、跨系统证据或并发控制。

## 成功与失败

成功是：人能低摩擦地持续研究真正重要的议题，阶段判断、行动与现实反馈准确回到 Learn-X；数月后仍能说明每次变化来自哪个文档版本，以及如何恢复。

失败是：用户被月度配额绑住，文档沦为 Base 镜像，系统把运行动作包装成认知进展，AI 为了写入量猜测，或无法解释/撤回历史。

## 本次关键决策

- 使用一个新的独立 Skill，不调用旧 `learn-x-question-review`。
- 空优先级按 P1、空研究状态按继续研究解释，不批量回填历史记录。
- 议题周期不设默认值；候选展示周期与优先级两层信息，普通候选先按短期、中期、长期、未分类分层，每层最多推荐两个，再在层内按优先级和历史注意力排序。临近截止的重大决策仍优先。
- 每月一份 Wiki 工作台和一条机器账本；后者仅处理幂等、恢复与审计。
- 纠错入口是编辑文档后重解析，或撤回上一版；P0 不支持聊天口述补丁。
- 周复盘 Workflow 暂停，待独立重做。
月度研究正文统一落在私有 Wiki「人生核心议题」的「细项研究」目录；Base 只保留账本、结构化议题与事件。历史上仅有 Base Docx token 的账本继续兼容，新建文档必须记录 Wiki node token。
