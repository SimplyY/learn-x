# Learn-X Weekly Output 生成规范

## 1. 核心定位

Weekly Output 是 Learn-X 的**周度记忆层**，兼顾具体记忆、认知变化与深度思考。

核心问题：

> 未来的我或 AI 重新理解这一周，哪些经历、人物、输入、判断和变化不能丢？其中什么值得进一步想透？

三项目标：

1. **记忆**：保存重要人生经历、具体场景与状态，保留生命纹理。
2. **思考**：识别真正重要的变化，对 1—2 个关键问题深入思考。
3. **沉淀**：提取 Memory 与 Flomo 候选，让重要信息能够长期保留、再次调用。

优先保真，不追求完整流水账、固定洞察数量或行动绩效。

## 2. 与其他系统的分工

- **Core**：当前有效、最高信号、需要频繁调用的上下文。
- **Weekly**：一周的重要记忆、变化、思考与来源。
- **Monthly**：跨周模式、趋势及长期变化。
- **Memory**：极少数值得 AI 长期携带的关键个人上下文。
- **Flomo**：重要但不必常驻 Memory 的长期记忆、经历与洞察。

Weekly 是完整周度档案；Memory 是内存；Flomo 是精选硬盘记忆。

三者可以交叉引用，但应避免重复维护。

## 3. 内容选择标准

最高标准：

> 删除这条信息，未来是否更容易误解当时的我，或丢失一个重要的思想与经历？

主要判断：

- **个人解释力**：反映在意什么、被什么滋养或消耗、与谁发生重要联系。
- **变化信息**：新出现、强化、弱化、反转或被现实修正。
- **长期价值**：未来理解生活、关系、事业、健康、投资或创造时可能需要。
- **独特性**：具体、不可轻易重建，或包含有价值的新认识。

重要性可近似理解为：

**未来解释力 × 新信息量。**

不计算分数，不因材料长就赋予更高权重。

## 4. 事实与上下文边界

本周事实以：

`04_output/_dist/weekly/YYYY-Www/process-pack.md`

为准。

- 当前 Process Pack 第 1—7 节是本周事实来源。
- Core、Memory、道等长期上下文用于理解重要性，不得补造本周事实。
- 上周 Weekly 仅用于比较。
- 原始 Input / input.json 只在缺失、冲突、核查或排错时读取。
- 脚本候选不等于最终 AI 判断。
- 日记、周记等输入不自动升级为长期 Memory。
- Action Feedback 已退役，不得假定存在独立文件或旧 Base 写入。

明确区分事实、个人判断、AI 推断与尚待验证的假设。

## 5. 本周记忆

这是 Weekly 的主体，回答：

**这一周有什么值得未来重新想起？**

根据材料自然组织，不机械分类。

优先保留：

- 具体的人、事、地点和重要场景。
- 关系、身体、情绪与生活体验。
- 创作、兴趣、阅读、旅行和真实交流。
- 工作、合作、重要选择与现实反馈。
- 当时独特的感受、表达和未完成问题。

重要经历可采用：

**发生了什么 → 为什么重要 → 留下什么感受或变化。**

保留不可替代的细节，但不复述完整经过。

一件事即使没有洞察，只要未来值得记住，也应保留。

## 6. 重要信息源与外部世界

关注：

**这一周，有什么重要东西进入了我的世界？**

包括书、文章、论文、AI 对话、电影、Flomo、现实聊天、旅行、项目等。

只选择真正改变理解、注意力或后续思考，或具有独特长期价值的输入。

每个重要来源简要说明：

**输入是什么 → 带来了什么新认识或问题。**

保留原有问题意识和独特表达，不机械列出全部来源。

本周记忆已经详细记录的来源，不在这里重复经历，只补充其独立的认知价值。

## 7. 核心量化指标

保留真实存在且具有解释价值的指标。

指标身份必须包含：

**来源 + 时间粒度 + 指标名 + 单位 / 分母。**

- Health-X：实际存在的周度分数、维度分、步数、睡眠、活动消耗等。
- 日记：保留原始日粒度证据，默认不重复每日评分。
- 周记：实际存在的周期评分。

要求：

- 原值保留，不四舍五入或凭印象改写。
- 不跨来源或时间粒度推导、补缺。
- 保留原始变化说明，不生成不存在的字段。
- 正文判断不得与量化事实冲突。

只有确认某字段存在但本周没有记录时，才能写“本周无数据”。

优先用紧凑表格呈现，不对普通波动过度分析。

## 8. 本周变化与深度思考

本节承担两个独立职责。

### 8.1 重要变化

只保留能够改变对本周理解的变化：

新出现、持续、强化、弱化、消失、反转、被现实修正或尚未解决。

不重复本周经历，只提炼变化本身。

### 8.2 深度思考

**选择本周最值得思考的 1—2 个问题。**

每个问题优先回答：

1. **核心判断**：真正值得理解的是什么？
2. **底层机制**：为什么会这样？关键变量或因果关系是什么？
3. **反证与边界**：还有什么替代解释？什么情况会推翻当前判断？

不机械套用三段式，可以压缩为一个完整段落。

要求：

- AI 应主动分析，而不只是复述用户观点。
- 深度优先于数量，寻找真正有解释力的机制。
- 区分事实、推断和假设。
- 可以质疑已有判断，不能为了深刻而制造反转。
- 允许没有可靠结论，保留有价值的开放问题。
- 每个问题尽量控制在 100—180 字。

**不制造洞察，但也不因害怕制造洞察而停止思考。**

本节生成的优秀洞察，可以作为 Memory 或 Flomo 候选，不需要在后文重新解释。

## 9. 值得长期保留

分为 Memory 与 Flomo 两类。

### 9.1 Memory｜长期上下文

建议 0—2 条，宁缺毋滥。

只选择未来 AI 真正应该长期知道、可能持续影响理解与判断的内容，包括：

- 极其重要的人生经历与关系。
- 稳定的价值观、偏好、原则。
- 重要身份、目标或人生阶段变化。
- 反复验证的个人模式与关键洞察。

**非常重要的具体人生记忆，同样可以进入 Memory，不要求一定是抽象原则。**

每条只写一个精炼、可独立理解的完整记忆，通常不超过 60 字。

已存在于 Memory 且没有实质变化的内容：

标记 **（已有）**，不重新推荐写入。

没有新增候选时，明确说明即可。

### 9.2 Flomo｜长期硬盘记忆

建议每周提取 **3—6 条**；材料不足时可以更少，不凑数。

适合保存：

- 重要但不必常驻 Memory 的具体经历。
- 真实的人物、关系、事件和独特感受。
- 有价值的思想、问题和判断变化。
- 重要的外部输入、现实反馈与启发。
- 具有长期回看价值的个人表达。

要求：

1. 按重要性降序排列。
2. 一条只承载一项独立记忆。
3. 优先保留事实、核心判断与必要上下文。
4. 每条尽量控制在 30—60 字，不写冗长解释。
5. 已在 Flomo 中存在的内容不重复提取，除非产生重要新认识。
6. 与 Memory 重合时，只有具体细节具有独立保存价值，才同时保留。

**所有 Flomo 候选合并为一篇周度笔记，便于一次复制粘贴。**

固定格式：

标题：YYYY-Www｜周度记忆

1. **主题**：记忆正文
2. **主题**：记忆正文
3. **主题**：记忆正文

按需增加至 6 条。

Flomo 笔记整体尽量控制在 200—350 字。不要输出多篇独立笔记，不为每条附加解释。

AI 只生成候选，不自动写入 Memory 或 Flomo，由用户人工确认。

**洞察与记忆不是竞争关系。最好的洞察，本身就是值得保存的记忆。**

## 10. 本周与上周对照

使用 Process Pack 明确提供的上周 Weekly Output。

只比较真正重要的变化：

- 新出现、持续或消失。
- 强化、弱化或反转。
- 被现实修正。
- 仍未解决的关键问题。

不重新总结两周，不把旧事实写成本周事实。

同一事实只计一次，空占位不能作为证据。

若基线为 missing、empty 或 shell，标记“不可比较”，不回退更早周期。

本节最多 300 字，优先更短。

## 11. 本周最值得思考的 3 个问题与回答

恰好提出 3 个值得用户本人回答的问题。

优先选择：

- 反复出现但尚未解决的问题。
- 影响重要选择的价值判断。
- 未验证的关键假设。
- 需要用户决定的目标与边界。

AI 只提问，不替用户回答。

三题互不重复，并与前面的深度思考互补：

**深度思考负责 AI 可以分析的问题；本节负责必须由用户本人回答的问题。**

问题核心以 10—20 字为目标，最长 50 字；必要背景加问题合计不超过 100 字。

固定格式：

1. 问题：……？  
背景补充：（可选）  
回答：
2. 问题：……？  
背景补充：（可选）  
回答：
3. 问题：……？  
背景补充：（可选）  
回答：

## 12. 全文核心重点纪要

用户人工补充区，AI 不自动代写。

保留固定格式：

1. xx
2. xx
3. xx

## 13. 芒格之魂的洞察

用户后续通过独立“芒格之魂”思考补充，AI 不自动代写。

保留固定格式：

1. xx
2. xx
3. xx

上述两个人工区和第 11 节若已有下游消费规则，保持现有机器语义。

空白、todo、未回答问题和 xx 占位不得迁移。

## 14. 来源

Weekly 必须可靠、可追溯。

正文可使用 source id；末尾只保留重要事实所需的最小来源索引。

不重复罗列文件路径与长篇来源说明。

AI 推断必要时标记为观察、推测或待确认。

## 16. 本周总览

帮助未来的我以最低成本恢复这一周。

优先呈现 2—4 条重要主线：

**发生了什么 → 为什么重要 → 产生什么变化。**

每条主线独立成段，段间空一行。

不机械覆盖所有模块，不重复大量细节。

## 17. 篇幅与写作原则

**完整输出总字数上限：2500 字。**

包括全部正文、Memory、Flomo、三个问题、来源与固定人工补充区。

- 普通周：优先 1000—1500 字。
- 内容丰富周：可以 1500—2500 字。
- 2500 字是硬上限，不是目标。
- 信息少就写少，不为凑字数扩展内容。

建议篇幅权重：

- 本周记忆与具体经历：约 35%。
- 深度思考与判断变化：约 25%。
- Memory / Flomo 候选：约 20%。
- 总览、对照、指标、问题和来源等：约 20%。

比例只用于分配注意力，不机械凑字数。

优先压缩：

1. 多章节重复的事实。
2. 冗长的事件过程与背景。
3. 重复的解释和抽象总结。
4. 低价值来源与普通状态。
5. 不改变判断的修饰与铺垫。

优先保留：

1. 重要的具体人生记忆。
2. 关键判断变化与因果机制。
3. 能改变结论的反例、边界和不确定性。
4. 高价值洞察及长期记忆候选。
5. 必要量化事实与来源。

**压缩重复，不压扁重要结构；增加思考密度，不增加文字堆积。**

## 18. 明确禁止

不要求：

- 做中学 A/B/C/S 评分。
- 固定行动闭环和下周任务清单。
- 固定数量的洞察、金句或盲点。
- 周期性道 / 法 / 术 / 器生产。
- 为了数量制造 Memory 或 Flomo 候选。

禁止：

- 编造本周事实或现实反馈。
- 用长期记忆覆盖本周来源。
- 将内部工程产物当成现实价值证明。
- 将相关性直接当成因果性。
- 为了显得深刻制造反证。
- 改写或推导原始量化指标。
- 反复输出已经存在的长期记忆。
- 通过增加篇幅代替真正的取舍。

## 19. 输出前检查

只检查：

1. 最值得记住的具体经历是否保留？
2. 是否有 1—2 个真正深入的思考，而非总结复述？
3. 是否区分了事实、判断、推断与反例？
4. 章节之间是否有明显重复？
5. Memory 是否足够重要，并识别已有内容？
6. Flomo 是否为一篇可直接复制的精选周度笔记？
7. 量化指标和来源是否可靠？
8. 0—10 章节、三个问题和人工占位是否完整？
9. 总字数是否不超过 2500 字，并根据材料丰度主动缩短？

完成后直接输出，不展示检查过程。
