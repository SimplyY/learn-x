# Weekly Output

请查看 `.agents/skills/learn-x-process/resources/weekly-output-rules.md`。

本次生成有一条不可覆盖的数据契约：`process-pack.md` 是事实源，规则文件是输出约束。判断量化指标时必须保留「来源 + 时间粒度 + 指标名 + 单位 / 分母」；Health-X 周度汇总与日记日粒度评分不是同一数据，不能互相推导。Weekly Output 默认只展示周度 Health-X 指标；日记评分仅在 Current Question 明确要求日趋势、异常或评分依据时引用，不要生成“其他规定指标”区。

若 Process Pack 第 9 节有 ready 的上周 Weekly Output，生成不超过 600 字的「本周与上周对照」章节，完成简短的跨周对照：优先比较两期总览、核心洞察、全文核心重点纪要、芒格之魂洞察和问题与回答；旧 Output 仅作对照，本周事实只来自当前 Process Pack。芒格洞察或用户回答尚未补齐时，只比较当前已存在的实质内容；空占位、未回答问题不能作为本周证据，也不要求之后重写对照。无有效基线时仍保留章节并标注不可比较，不回退到更早周期。对照保持简短，不显示百分比或分数，不重复计权。

本周 3 个问题由 AI 提问、用户补答；问题核心以 10–20 字为目标、最多 50 字，可另列背景补充，问题与补充合计最多 100 字。不得替用户编造回答。
