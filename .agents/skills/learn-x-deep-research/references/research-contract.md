# 深度研究契约

## 对象与命名

- 一次深度研究 = 一篇 Wiki 文档，标题即主题（不带日期前缀），父节点固定为年目录 `深度研究-YYYY`（不存在则自动创建）。
- 深度研究不属于月份或季度；按年归档，年目录本身是索引页，只收录直接子节点。索引按标题 `localeCompare(..., "zh")` 排序，不做按期去重。

## 模板

模板只固定八个检查点：研究问题 / 为什么现在研究 / 当前认知（研究开始前）/ 研究主体 / 反证与未知 / 阶段性结论 / 认知变化 / 下一步。研究主体是自由研究区，不强制章节。

`当前认知` 由脚本注入，每个关联议题一个区块：类型｜周期｜优先级、当前判断、判断置信度、最大未知、改变判断的条件、下一步、近期认知事件（最多 5 条，按时间倒序，排除已撤回）。这些是研究开始前的事实快照，不是研究结论。

## 边界

- 脚本对 Base 只读（`议题`、`认知事件` 两表）；任何 Base 写入都是契约违反。
- 不存在研究结束后的回填管线：没有 proposal、apply、rollback。认知事件由人在 Base 手工记录（或经用户确认后由 agent 代填），`来源链接` = 研究文档 URL、`来源系统` = Learn-X；没有变化就不产生事件。
- 研究与议题的多对多关系体现在文档模板的注入区块中；不新增 Base 字段。

## 失败语义

- 同名文档：空白 → 写入模板（恢复中断的创建）；已有内容 → 视为研究已存在，幂等返回原链接，绝不改写文档一个字。
- 同标题跨年出现多份 → 直接失败，要求人工合并或改名，不猜测归属。
- 回读校验：文档写入后必须回读，包含标题和全部议题编号锚点，否则视为失败。
- Wiki 空间非私有、目录改名/移动、分页异常 → 失败关闭，停止执行。
- 目录页由 `index` 全量重建，可随时自愈；重建失败不影响已创建的研究文档。
