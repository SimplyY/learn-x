# 一键深度研究

深度研究是 Learn-X 的一等研究资产：**一次深度研究 = 一篇 Wiki 文档**，放在私有 Wiki「人生核心议题」的顶级目录「深度研究」下。它不属于任何月份或季度；季度负责盘点、月度工作台负责注意力调度、深度研究按需发生。先读 [产品文档](../../../docs/DEEP_RESEARCH.md)；创建前读 [研究契约](references/research-contract.md)。

运行 `npm run inquiry:deep-research -- <command>`。脚本只做确定性读写：读 Base（议题、认知事件）、写 Wiki（研究文档 + 目录页），**对 Base 零写入**。

## 命令

- `create --title 主题 [--issue-id IQ-0001]... [--question 一句话问题] [--date YYYY-MM-DD]`：一键发起。自动创建 `深度研究｜YYYY-MM-DD｜主题` Wiki 文档、注入研究模板与关联议题的当前判断/最大未知/近期认知事件、重建目录索引，返回 Wiki 链接。`--issue-id` 可多个（多对多关联议题）；不带议题时从临时问题发起。同日多份研究合法。
- `context [--issue-id IQ-0001]...`：组装 ChatGPT 深度研究上下文包（议题判断快照 + 认知事件史 + 已有研究清单），markdown 输出；不带议题时覆盖全部活跃议题。
- `index`：全量重建「深度研究」目录页（新 → 旧），可随时自愈。
- `setup`：校验 Wiki 三目录并初始化目录页。

## 规则

- 幂等恢复：同名文档存在且为空白 → 写入模板；已有内容 → 视为研究已存在，返回原链接，绝不改写用户研究。
- 议题编号以 Base `议题` 表为准；未找到即报错，不猜测。
- 研究造成真正认知变化时，由人（或经用户确认后由 agent）在 Base「认知事件」新建记录：`来源链接` 填研究文档 URL、`来源系统` 选 Learn-X、`关联议题` 勾选对应议题。本 Skill 不自动创建事件。
- 研究正文由人维护；模板只固定检查点，不把研究变成填表。
- Wiki 空间、目录漂移或分页异常一律失败关闭，不降级。
