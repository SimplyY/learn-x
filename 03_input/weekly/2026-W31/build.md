## 2026-08-03 全局 Codex / Code X Build 复盘

**覆盖期：2026-07-27（周一）至 2026-08-02（周日），Asia/Shanghai，ISO 2026-W31。**

### 本周总览

本周的主线不是增加更多自动化入口，而是把已有工作流的判断、证据和回读做实：

- Read-X 将内容评分收敛为单一、可失败关闭的运行时契约；
- Voice-X 建立从转写、保留、回填到 Learn-X 消费的可验证通路；
- 研究、知识回顾和群级决策分别补上持久化、结构化归档与逐群判断。

这使「AI Builder」的重点从能生成，推进到能判断、能复用、能追责。

### 最核心的五件事

1. **Read-X：内容质量判断由散落规则收敛为一个评分契约。**
   - `content_scoring.py` 成为引用校验、硬门、权重、路由与深度的唯一入口。
   - v3.15 采用证据/洞见/可迁移性 0.35/0.35/0.30；不完整正文、旧 schema、冲突或无效引用均失败关闭。
   - Link Card 与 Long Read 改为消费结果，不再各自重算。价值是以后校准只改一处，避免内容在不同出口被判成不同结论。

2. **Voice-X：建立可回填、可验证的语音输入闭环。**
   - 新增转写工作流、脚本与显式 Learn-X 集成测试，并修正完整周边界。
   - 随后把 reserve/backfill 改为文档引用模式，减少重复搬运并保留可追溯来源。
   - 这补齐了「捕捉 → 结构化 → 周输入」的薄弱一段；真实语音使用频率和人工体验仍需后续观察。

3. **Research-X：知识回顾从临时链接升级为可持续回读。**
   - 智慧回顾卡改为内嵌图片，解决临时链接 24 小时失效。
   - 入库加入道/法/术/器层级标准，Base 调用统一补 `--as user`。
   - 新增 GitHub intelligence，并调整人物情报路由；研究成果开始更稳定地进入可检索的知识结构。

4. **全局 Skills：群级决策改为只读、逐群、可审计。**
   - `ywnew` 移除总量阈值/全发式决策，新增只读 `check.js` 固化逐群判断。
   - 同期清理 `ywnext` 冗余拼装和检查逻辑，并建立 W31 problem ledger。
   - 这是一种可复用的安全模式：先输出决策证据，再决定是否执行外部动作。

5. **Learn-X：周输入和记忆管线补全可追溯的接入点。**
   - 新增 Voice 周采集与测试，补齐时间采集细节和 weekly-memory 解析。
   - W30 输入、季度 Memory 与周报依据同步更新，说明外部行动证据已能更完整地进入认知系统。
   - 月度自动化仍停在 Phase 1 人工审核门，不应把「已生成草稿」误判为完整闭环。

### 跨项目能力变化

- **单一事实源**：评分策略、路由和边界集中到一个运行时或规则源，消费者只消费结果。
- **失败关闭**：证据不完整、引用无效、配置冲突时宁可不推进，避免自动化把不确定性伪装成完成。
- **可回读证据**：从临时链接、碎片文本、全量群发，转向内嵌卡片、文档引用、逐群检查和问题台账。

### 对 AI Builder、学习者与知行合一的意义

- 对 AI Builder：可复用的不是某个脚本，而是「先校验证据，再路由动作，最后保留回读」的工作模式。
- 对学习者：语音、时间和研究不再只是输入堆积，开始有进入周复盘与长期记忆的固定入口。
- 对知行合一：本周强化的是行动证据和反馈边界；尚不能证明这些改变已带来稳定的学习或行为改变。

### 取舍

**必须做**

- 用同一批真实内容完成 Read-X 七锚校准和 Link Card/Long Read/飞书端到端验收。
- 对 Voice-X 跑至少一次真实周输入，检查转写、引用、回填与 Learn-X 消费是否完整。

**值得做**

- 为逐群判断和智慧回顾记录真实误报、漏报与回读完成率，再判断阈值或策略是否需要调整。
- 在月度自动化的人审后，再决定是否进入 Process Pack、Output 和 Memory 阶段。

**暂时不做**

- 不新增评分维度、第二套路由器或新的集中入口；当前瓶颈是校准和真实用户路径，不是功能数量。
- 不把本地测试或 dry-run 写成外部体验已验证。

### 当前最缺与下周优先级

当前最缺的是**真实用户路径的回读数据**：评分是否与人的判断一致，语音是否确实减少输入摩擦，回顾卡是否被持续使用。

下周优先级：

1. 先完成 Read-X 真实样本校准与端到端验收；
2. 再跑 Voice-X → Learn-X 的一轮真实周输入；
3. 汇总智慧回顾与逐群判断的真实反馈，只有证据显示问题时才继续改策略。
